# Кастдев-таргетинг по базе «промышленность.xlsx»

> Создано 2026-06-18. Задача: отобрать из реестровой базы (3517 компаний) кандидатов на звонок для кастдева РОПов про опросные листы.
> Метод: pre-фильтр в Python по отрасли/размеру/прибыли → проверка сайтов через Playwright (наличие сущности «опросный лист» + контакты продаж).

## Главный вывод (меняет принцип отбора)

**«Опросный лист» — узкий отраслевой паттерн, а не общепромышленный.** Он нативно живёт только там, где клиент физически не может купить без передачи параметров: **измеряемое / подбираемое оборудование** — расходомеры, КИПиА, датчики, трубопроводная арматура, насосы, теплообменники, щитовое/распределительное оборудование.

У кого опросника НЕТ (проверено): металлоконструкции, машзаводы (горная техника), пищёвка, ЖБИ — там воронка идёт через **тендеры, проекты, прямые контракты, дилеров**, а не «заполни опросник → расчёт».

→ Главный фильтр отбора — **не прибыль, а отрасль = ЭМИС-подобное оборудование**. Прибыль и размер — только вторичные гейты (см. ниже).

## Ответы на три вопроса

**1. Прибыльные или «неудачники»?** — Прибыльные **средние**, не гиганты и не убыточные.
- Убыточные исключаем: РОП на убыточном заводе тушит пожары, видимость воронки — не его боль №1; плюс шумный сигнал (умирают по другим причинам).
- Гигантов (крупные, прибыль млрд+) исключаем: до РОПа не дозвонишься, гейткиперы, закупки/госконтракты. Они всплыли в топе по прибыли — это ловушка сортировки.
- Sweet spot: **средние предприятия, прибыль 2025 > 0**, отрасль ЭМИС-типа. Там РОП существует как роль И достижим звонком.

**2. Есть ли на сайте сущность «опросный лист»?** — Проверяется Playwright'ом, сильный сигнал.
- Если опросник в **меню/первом экране** (как у ЭМИС: `/order/`) — продажа буквально построена на нём → видимость «кто открыл/завис/на каком параметре отвалился» структурно болит. Лучший кандидат.
- Если только «расчёт / заявка / заказ» без опросника — слабее.
- У старых арматурных заводов опросник часто PDF глубоко в каталоге + кривой сайт (битый HTTPS) — средний сигнал.

**3. Прямые контакты отдела продаж?** — Частично.
- Современные сайты дают `sales@…` + 8-800 (ЭМИС: `sales@emis-kip.ru`; Феррум-С: `sales@ooo-ferrum.ru`).
- Большинство промсайтов — только общий `info@/mail@` + телефон приёмной.
- **Имени РОПа на сайте нет почти нигде** (в реестровой базе тоже только директор). Выход на РОПа = звонок в приёмную «соедините с руководителем отдела продаж» (Путь Б-1) либо обогащение по домену (Контур.Компас/GetProspect).
