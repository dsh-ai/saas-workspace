# Audiences

## Назначение
Подготовка контактных списков (e-mail, телефон) для загрузки сегментов в **Яндекс.Аудитории**.

## Источники
- `промышленность.xlsx`, `промышленность_sales emails.xlsx` — исходные базы (выгрузки по отрасли).
- `emails.csv` — экспорт e-mail из xlsx (UTF-8 BOM, 2 колонки `Электронный адрес` + `Sales email`, в одной ячейке могут быть несколько адресов через `, `).
- `phone.csv` — экспорт телефонов (multi-phone в одной ячейке через `\n`, формат `+7 (XXX) XXXXXXX`).

## Формат для Яндекс.Аудиторий (правила нормализации)
Полные требования: `~/.claude/projects/.../memory/reference-yandex-audiences-format.md`.

**Email** (`emails-yandex.csv`):
- Один адрес в строке, lowercase, trim, без заголовка, отсортированы.
- Извлекать из всех колонок исходника.
- Глобальная дедупликация.
- Regex: `[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}`.

**Телефоны** (`phones-yandex.csv`):
- Только цифры, формат `7XXXXXXXXXX` (11 цифр).
- `8XXXXXXXXXX` → `7XXXXXXXXXX`; 10-значные → префикс `7`.
- Один номер в строке, без заголовка.
- Глобальная дедупликация.

**Не группировать** несколько контактов в одну строку через запятую — даже если в исходнике они принадлежат одной организации. Яндекс.Аудитории работают с записями 1:1.

## Отбор кандидатов на кастдев РОПов (из `промышленность.xlsx`)

Когда пользователь просит отобрать из базы компании на звонок для кастдева про опросные листы:

1. **Главный фильтр — отрасль, НЕ прибыль.** «Опросный лист» нативен только у производителей **измеряемого/подбираемого оборудования**: расходомеры, КИПиА, датчики, трубопроводная/газовая арматура, насосы, теплообменники, щитовое/распределительное оборудование. У металлоконструкций, машзаводов, пищёвки, ЖБИ, серийной товарки (каталог) — опросника нет (тендеры/проекты/дилеры). Эталон — **ЭМИС** (`emis-kip.ru/order/`), ищем «таких как ЭМИС».
2. **Прибыльные СРЕДНИЕ.** Убыточных — вон (шумный сигнал). Гигантов (прибыль млрд+) — вон (гейткиперы, всплывают в топе по прибыли = ловушка сортировки). Средние — РОП есть как роль И достижим звонком.
3. **Подтверждать опросник Playwright'ом.** Метод: `browser_navigate` → `browser_evaluate` (искать `опросн` в тексте/ссылках + `tel:`/`mailto:` + упоминание «отдел продаж»). Снапшоты уходят в файл — токены целы. Сильнейший сигнал — опросник в меню. «Нет на главной» ≠ «нет опросника» (у арматуры/КТП/теплообмена он на страницах товара). Часть старых промсайтов недоступна по SSL/DNS — это норма, помечать и идти дальше.
4. **РОПа в базе НЕТ** — только директор (гендир/директор); имени РОПа нет и на сайтах. Выход = звонок в приёмную «соедините с руководителем отдела продаж» (Путь Б-1) либо обогащение по домену (Контур.Компас/GetProspect/Snov.io).
5. **Колонки `промышленность.xlsx`** (шапка на строке 4, данные с 5): 1 Наименование, 5 Руководство, 6 должность, 7 Телефон (multi через `\n`), 8 Эл.адрес, 9 Сайт, 14 Регион, 15 Вид деятельности/отрасль, 19 Размер компании, 28/29 Чистая прибыль 2024/2025. Внимание на подстрочные ложняки keyword-фильтра («гидравлической извести», «столовых приборов», «бытовых приборов» — мусор, исключать).
6. **Артефакты:** `custdev-targeting.md` (методика), `custdev-calllist.csv` (рабочий список 45 средних с приоритетом). Подробности — память `project-custdev-targeting.md`.
