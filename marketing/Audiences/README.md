## Отбор кандидатов на кастдев РОПов (опросные листы)

Та же база `промышленность.xlsx` используется не только под Яндекс.Аудитории, но и под **отбор компаний на звонок для кастдева** (красная ячейка трекшн-карты — подтверждение проблемы).

**Главный принцип:** «опросный лист» — **узкий отраслевой паттерн**, а не общепромышленный. Он живёт у производителей **измеряемого/подбираемого оборудования** (расходомеры, КИПиА, датчики, трубопроводная/газовая арматура, насосы, теплообменники, щиты). У металлоконструкций, машзаводов, пищёвки, серийной товарки его нет. **Эталон — ЭМИС** (`emis-kip.ru/order/`).

→ Фильтруем **по отрасли, не по прибыли**; берём **прибыльные средние** (РОП достижим звонком, не гигант-гейткипер). Подтверждать опросник — Playwright'ом по сайту. РОПа в базе нет (только директор) → выход через приёмную «соедините с РОПом».

Приоритет 1 на звонок (опросник на сайте подтверждён): **ЭМИС, ХАКЕЛЬ (k2el.ru), ЗНИГО, ГАЗАППАРАТ**.

## Что внутри `промышленность.xlsx` (для обзвона/outreach)

Реестровая выгрузка (тип СПАРК/ЕГРЮЛ): **3506 компаний**, у всех ФИО руководителя, у **3249 — телефон**. Ключевые колонки (шапка на строке 4): `Наименование`, `Руководство` (ФИО), `Руководство-должность`, `Телефон`, `Эл.адрес`, `Сайт`, `Регион`, `Размер компании`, выручка/прибыль 2024–2025.

⚠️ **Должности — только первые лица** (2404 гендир, 707 директор, 292 УК). **РОПов в базе нет** — в реестрах фиксируется только директор. Для выхода на РОПа: либо звонить по телефону компании и просить соединить (Путь Б-1, см. память `call-script-b1-rop.md`), либо обогащать по домену через Контур.Компас / GetProspect / Snov.io.

## Формат Яндекс.Аудиторий
- E-mail: lowercase, один адрес в строке, без заголовка.
- Телефон: только цифры, 11 знаков с `7` в начале, один номер в строке, без заголовка.
- **Не группировать** несколько контактов в одну строку (даже если они одной организации).

Минимум для сегмента — 100 записей; рекомендуется 1 000+.

## Как обновлять
1. Выгрузить новый xlsx → сохранить как `emails.csv` / `phone.csv` (UTF-8).
2. Запустить нормализацию (см. inline-скрипты в `CLAUDE.md` или вынести в `tools/audiences/`).
3. Загрузить готовые `*-yandex.csv` в Яндекс.Аудитории как сегмент по списку.
