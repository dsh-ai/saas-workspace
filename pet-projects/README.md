# pet-projects — побочные продукты

## Роль домена
Здесь живут идеи и запуски **пет-продуктов** — небольших продуктов вне Unilist, которые
строятся вайбкодингом за выходные и дальше **не требуют ежедневного внимания**.

Главное ограничение домена: **Unilist остаётся основным фокусом.** Пет-продукт, который
начал есть больше ~4 часов в неделю, считается провалившим свой главный критерий —
и закрывается, а не «оптимизируется».

## Файлы
- `idea-filter.md` — жёсткий фильтр и скоринг. **Читать до генерации идей**, не после.
- `ideas.md` — текущий пул идей со скорингом + разбор топ-3 + сознательные «нет».
- `discovery-playbook.md` — ритуал добычи идей из 10 источников (Reddit/GummySearch, HN, PH, vc.ru…)
- `signals.md` — журнал сырых сигналов с источниками и цитатами.

## Правила
1. Идея не попадает в `ideas.md` без прохода по hard-фильтрам из `idea-filter.md`.
2. Сигнал не засчитывается без **дословной цитаты** носителя боли (правило перенесено
   из кастдева РОПов — см. `../tracking/interview-guide.md`). Пересказ не скорим.
3. У каждого запущенного пет-продукта заранее прописан **план смерти**: как он выключается
   без ущерба репутации и без миграции пользователей.
4. Кросс-доменное влияние (деньги, время, юрриски) — в `../CENTRAL_STATE.md` и `../CHANGELOG.md`.
