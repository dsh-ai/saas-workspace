# Сырьё интервью с РОПами

Сюда — дословные диалоги, по файлу на интервью.

**Имя файла:** `ГГГГ-ММ-ДД-rop-<компания-или-кто>.md`
Пример: `2026-06-20-rop-metallotorg.md`

**Что класть:**
- Дословную расшифровку (целиком) ИЛИ дословные куски + цитаты.
- Чем сырее, тем лучше — НЕ пересказывай своими словами, скоринг идёт по формулировкам РОПа.
- Если запись голосом — сначала расшифруй в текст (Telegram voice-to-text / Whisper / руками), потом сюда.

**Что НЕ нужно:** свои выводы и оценки — это сделаем вместе при разборе.
